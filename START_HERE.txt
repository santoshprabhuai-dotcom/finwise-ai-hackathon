STEP 1: Get Your Credentials (10 minutes)

│ 1. Supabase Setup                                       │

│    c. Copy SQL from supabase_schema.sql and RUN it      │
│    d. Get NEXT_PUBLIC_SUPABASE_URL and               │
│       NEXT_PUBLIC_SUPABASE_ANON_KEY                  │
│                                                         │
│ 2. OpenRouter Setup                                     │
│    a. Go to openrouter.ai/signup                        │
│    b. Get your API key                                  │
│    c. Save as OPENROUTER_API_KEY                       │
└─────────────────────────────────────────────────────────┘

STEP 2: Push to GitHub (5 minutes)
┌─────────────────────────────────────────────────────────┐
│ 1. Go to github.com/new                                 │
│ 2. Create repo: finwise-ai-hackathon                    │
│ 3. Make it PUBLIC                                       │
│ 4. Upload all files from this folder                    │
│    OR push via Git command line                         │
└─────────────────────────────────────────────────────────┘

STEP 3: Deploy to Vercel (3 minutes)
┌─────────────────────────────────────────────────────────┐
│ 1. Go to vercel.com/new                                 │
│ 2. Connect GitHub                                       │
│ 3. Select your repo                                     │
│ 4. Add 3 environment variables:                         │
│    - NEXT_PUBLIC_SUPABASE_URL                          │
│    - NEXT_PUBLIC_SUPABASE_ANON_KEY                     │
│    - OPENROUTER_API_KEY                                │
│ 5. Click Deploy                                         │
│ 6. WAIT 2-3 MINUTES                                     │
│ 7. GET YOUR LIVE URL! ✨                                │
└─────────────────────────────────────────────────────────┘
